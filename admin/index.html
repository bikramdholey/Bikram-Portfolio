Admin

Edit the website — sign in with the site owner's GitHub account.

🔐 Log in to the Admin panel

Sign in with the GitHub account bikramdholey (your GitHub username and password). Only that account can save changes; anyone else who opens the panel can't edit anything.

📷 Memories — upload photos

  • Open the photo manager — open an album folder (or create a new one) and upload pictures. Each folder is one album.
  • Album titles are edited under Memory album titles.
  • Large phone photos are shrunk automatically and iPhone HEIC photos are converted to JPG when the site is published.

📚 Publications, CV & experience

  • Edit the CV in Overleaf — journal articles, book chapters, conferences, education, experience, awards, courses and references all come from the CV.
  • The website copies the CV automatically every 3 hours. To copy it right away, use Sync CV & publications from Overleaf now in the Admin panel's actions menu.

✏️ Text, links & pages

  • Site text — the About Me introduction, and the Publications page subtitle and quote.
  • Social / research profile links
  • Institution website links (used on the About page)
  • Teaching page · Contact page · Projects
  • Other site images

🚀 Publishing

  • Every save in the Admin panel publishes the website automatically within a few minutes.
  • Progress and any errors: GitHub Actions.
